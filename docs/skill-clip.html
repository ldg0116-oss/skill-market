한 장면에 한 가지 요점. 장면표부터 자막·내레이션 검수까지 적용하는 제작 규칙입니다.

검증 전 초안 · 수동 적용
완성 영상이나 개선 효과가 검증된 스킬은 아닙니다. 복사 가능한 제작 지침이며 영상 생성·게시를 자동 실행하지 않습니다.

이럴 때 사용하세요

잘 맞는 작업

사진과 사실 자료를 바탕으로 짧은 설명 영상을 만들 때. 자막이 길거나 내레이션이 딱딱해 수정 기준이 필요할 때.

별도 확인이 필요한 작업

정밀한 상품 재현, 의료·법률 판단, 실시간 뉴스, 사용 권리가 없는 자료. 이 규칙이 사실 검증이나 저작권 확인을 대신하지 않습니다.

준비할 자료

독자가 해결할 질문 하나, 확인된 사실과 출처, 사용 가능한 사진, 원문 안내 문구가 필요합니다. 대본 작성 도구·음성 도구·영상 편집 도구의 이용 조건은 각각 확인하세요.

확인된 실행 환경: 아직 없음 · 호환성 검증 전

사용 순서

  1. 자료를 입력하고 장면표 작성
  2. 출처와 대본을 검토한 후 음성 생성
  3. 실제 음성 길이에 맞춰 사진·자막 배치
  4. 휴대전화 크기로 읽고 소리를 들어 검수
  5. 수정 내역과 시간을 기록하고 결과 보존
발행 전 체크리스트
  • 제목의 질문에 실제로 답하는가?
  • 자막이 잘리거나 너무 빨리 사라지지 않는가?
  • 숫자·약어·고유명사가 정확하게 들리는가?
  • 사진의 핵심이 가려지지 않는가?
  • 사진 권리·AI 연출·제휴 고지를 확인했는가?
  • 원문 링크가 해당 글을 여는가?
