이번 주,
시험해 볼 만한 스킬.

매주 새로 올라온 스킬 가운데 직접 검증하고 시험해 볼 만한 것을 5개쯤 고릅니다. 공개 문서와 공개된 수치만 보고 고른 것이라, 실제로 잘 되는지는 돌려 봐야 압니다.

아직 올라온 추천이 없습니다첫 추천은 2026.11.23 (월)에 올라옵니다. 그 뒤로 매주 이 자리가 바뀝니다.

어떻게 고르나요?

인기가 아니라, 개발자가 아닌 1인 운영자에게 쓸모가 있고 공개 문서만으로 시험 방법과 준비 부담을 가늠할 수 있는 스킬을 고릅니다. 별 수와 설치 수는 점수에 넣지 않습니다.

무엇을 새 스킬로 보나요?
  • 최근 14일 안에 처음 공개된 것
  • 최근 14일 안에 쓰는 방법이나 대상 업무가 실질적으로 바뀐 것
  • 공개 후 90일 이내인데 그동안 다루지 않은 것은 주 1개까지
  • 공개일을 확인할 수 없으면 보류
이런 것은 먼저 뺍니다
  • 원본 파일을 읽을 수 없거나 설명과 실제 지시 내용이 다른 것
  • 글쓰기·콘텐츠·문서·조사·홈페이지 업무와 이어지는 사용 장면이 없거나 개발·서버 운영이 주목적인 것
  • 코드 수정, 서버 구축, 복잡한 터미널 작업이 꼭 필요한 것
  • 실행 환경이나 설치 절차가 빠져 시험을 시작할 방법이 없는 것
  • 비밀번호 입력, 불필요한 개인정보 전송, 파일 삭제, 자동 게시를 요구하면서 범위를 설명하지 않는 것
  • 입력과 기대 결과를 정할 수 없어 검증을 설계할 수 없는 것
점수 기준 (항목마다 0~4점, 비중을 곱해 100점 만점)
기준비중무엇을 보는지
실제 업무 적합성25%반복 업무에 쓸 장면과 결과물이 분명한지 봅니다.
비개발자 준비 부담20%설치·계정 연결·설정 단계가 적고 안내가 쉬운지 봅니다.
검증하기 쉬운 정도20%작은 시험으로 확인하고 기존 방식과 비교할 수 있는지 봅니다.
문서와 동작의 투명성15%실제 지시, 외부 연결, 권한, 한계가 드러나 있는지 봅니다.
한국 사용자에게 설명할 가치10%한국어 자료나 국내 사용자의 업무에 맞는지 봅니다.
기존 후보와의 차이10%이미 다룬 것과 달리 새로 시험할 질문이 생기는지 봅니다.
5개를 채우는 규칙
  • 먼저 빼는 조건을 통과하고 70점 이상인 것에서 고릅니다.
  • 글·SNS, 엑셀·문서, 조사·학습, 홈페이지 가운데 3개 분야 이상을 넣고, 같은 분야는 2개까지입니다.
  • 화면 조작 중심인 것을 3개 이상, 계정 연결이나 추가 설정이 필요한 것은 2개까지 넣습니다.
  • 비슷한 것은 1개만 넣습니다.
  • 5개가 안 되면 있는 만큼만 추천하고 이유를 적습니다. 개수를 맞추려고 기준을 낮추지 않습니다.
  • 한 번 추천한 것은 4주간 다시 추천하지 않습니다.
