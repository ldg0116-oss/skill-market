AI 스킬을 공부하며 글·이미지·영상을 직접 만듭니다. 잘된 결과뿐 아니라 부족한 점과 실제 반응도 함께 기록합니다.

채널마다 다른 역할

홈페이지에는 실험 조건과 스킬을, 블로그에는 자세한 제작 과정을, 인스타그램과 클립에는 결과와 핵심 차이를 담습니다.

블로그 방문

인스타그램과 JEJUINSIDER 주소는 확인 후 연결할 예정입니다.

공개 원칙

실행하지 않은 결과를 만들지 않습니다. 사용한 모델과 수정 내용을 기록합니다. 한 번의 성공을 정답으로 말하지 않습니다. 광고·협찬·제휴 관계는 해당 콘텐츠에서 밝힙니다.
