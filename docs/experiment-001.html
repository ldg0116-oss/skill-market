바꾸는 것과 고정하는 것

고정 조건

주제·사실·사진·사진 순서·9:16 비율·화자·음악 사용 여부·마지막 안내 문구. 25초를 목표로 실제 길이를 기록합니다.

변경 조건

자막은 한 장면 한 요점과 최대 두 줄. 음성은 짧은 구어체 문장과 자연스러운 쉼. 필요한 타이밍 조정도 기록합니다.

실행 순서

  1. 주제·대상·공식 출처와 기준일 확정
  2. 같은 자료로 네 버전 제작, 원본 보존
  3. 버전 이름을 가리고 순서를 바꿔 평가
  4. 문제 구간을 기록하고 최종본 선정
  5. 블로그·인스타·클립에 맞춰 공개 후 관찰

어떻게 좋아졌다고 판단하나요?

이해도, 자막 가독성, 음성 자연스러움과 선호 이유를 기록합니다. 가능하면 제작에 참여하지 않은 3~5명이 평가하고, 혼자 평가하면 자체 평가라고 밝힙니다.

점수보다 읽기 어렵거나 발음이 어색했던 구간을 우선합니다. 한 편의 결과를 모든 모델과 소재에 일반화하지 않습니다.
